Project Overview

The OctoNyteCPU is a 32-bit in-order RISC-V processor with 4-issue, 8-thread capability, built in Chisel and verified using Verilator. My role: design and run directed/randomized testbenches for LoadUnit, StoreUnit, ALU32, BranchUnit, and immediate instructions (e.g., ADDI).
